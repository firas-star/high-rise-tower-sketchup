HIGH-RISE TOWER — AutoCAD model
================================

File: High-Rise-Tower-AutoCAD.dxf
Format: AutoCAD 2010 DXF (AC1024)
Units: meters
Coordinates: Z up, origin at the southwest corner of the site, plaza at Z = 0

OPEN
----
AutoCAD, AutoCAD LT, BricsCAD, or DraftSight:

  File → Open → High-Rise-Tower-AutoCAD.dxf

It is a 3D model (20,418 faces), not a flat drawing.
After it opens: View → Visual Styles → Shaded, then
View → 3D Views → SW Isometric.
